# Antigravity Handoff — 9Router Project

## Mission

Set up a local 9Router AI gateway and integrate Antigravity as the first AI client.

## Read first

1. PRD.md
2. TECHSTACK.md
3. ARCHITECTURE.md
4. SETUP.md
5. SECURITY.md

## Phase 1 — Verify environment

Check:

```bash
node --version
npm --version
docker --version
```

Required:
- Node >= 20
- npm >= 10

## Phase 2 — Install

Preferred desktop route:

```bash
npm install -g 9router
9router
```

Alternative Docker:

```bash
docker run -d   --name 9router   -p 20128:20128   -v "$HOME/.9router:/app/data"   -e DATA_DIR=/app/data   decolua/9router:latest
```

## Phase 3 — Validate

Check:

```text
Dashboard: http://localhost:20128/dashboard
API:       http://localhost:20128/v1
```

Validate:
- dashboard loads;
- provider page loads;
- API key can be generated;
- `/v1/models` works;
- at least one provider is connected.

## Phase 4 — Antigravity

Configure Antigravity against:

```text
Base URL = http://localhost:20128/v1
API Key  = <key generated by 9Router>
Model    = <currently available model ID>
```

Do not guess model IDs. Query the live model list.

## Phase 5 — Provider test

Connect Provider A and Provider B.

Test:

```text
A succeeds → response
A fails    → B succeeds → response
```

Record:
- provider;
- model;
- latency;
- status;
- error;
- whether streaming works.

## Phase 6 — Token saver

Enable/test RTK only after basic routing works.

Compare:
- request before compression;
- request after compression;
- output quality;
- token usage.

Do not treat the advertised 20–40% saving as guaranteed for every workload.

## Phase 7 — Deliverables

At the end, produce:

```text
INSTALL_RESULT.md
PROVIDER_MATRIX.md
ANTIGRAVITY_CONFIG.md
TROUBLESHOOTING.md
```

Include exact installed version and commands actually used.

## Rules

- Do not expose 20128 publicly.
- Do not modify provider credentials into source code.
- Do not invent unsupported model IDs.
- Do not bypass provider Terms of Service.
- If documentation conflicts with the installed version, trust the installed source/release notes and record the discrepancy.
